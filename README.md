# SCULPT

Цифровой каталог и презентационный сайт проекта SCULPT.

Проект создан как самостоятельный цифровой продукт: от структуры и визуальной концепции до разработки и публикации на сервере.

## О проекте

SCULPT — веб-сайт-каталог с акцентом на визуальную подачу объектов и спокойную музейную эстетику.

В проекте реализованы:

- каталог и представление объектов;
- адаптивная веб-верстка;
- структурированная система страниц и компонентов;
- визуальная система проекта;
- форма обратной связи;
- публикация на отдельном сервере.

## Технологии

- Astro
- TypeScript
- Tailwind CSS
- Vite
